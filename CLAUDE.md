# Quarto

## Where things live

- `docs/PRD.md` — formal product requirements. Source of truth for scope.
- `wiki/` — Obsidian vault. Project state, decisions, daily logs, research.
- `wiki/CLAUDE.md` — wiki conventions. Read before writing notes.

If a request conflicts with the PRD or a `notes/decision-*.md` note, surface the conflict before coding.
