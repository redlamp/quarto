## Gotchas learned

- Next.js 16: `ssr: false` in `next/dynamic` is forbidden in Server Components. Page must be `'use client'` to use it.
- drei `Outlines` with `screenspace` and thickness >= ~3 paints the whole viewport with the outline color — use world-space thickness (e.g., `thickness={0.05}`) instead.
- boardgame.io `Client({ debug: true })` (default in dev) injects a Debug Panel that intercepts pointer events and breaks Playwright. Pass `debug: false` for app code; tests can still assert via the same path.
- Husky pre-commit on Windows worktrees needs `#!/bin/sh` shebang + `.gitattributes` LF line endings (already applied; see global memory note `tools/husky-windows-worktree.md`).
